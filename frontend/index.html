⚡ How to Run the Backend (GitHub Codespaces)
1
Open your GitHub repo → Click Code → Codespaces → Create codespace
2
In the Codespace terminal, run:
bash start.sh
3
Click Ports tab → Port 8000 → 🌐 icon to get your public URL (looks like https://xyz-8000.app.github.dev)
4
Paste that URL into the API URL field below ↓
⚙️ Backend API URL
Paste your Codespaces port URL here.
Make sure port 8000 is set to Public in the Ports tab.
